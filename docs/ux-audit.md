保持已确认的大幅轮播：图片光影、缓慢推镜、缩略图进度、屏内设备预览与 PhotoSwipe 全屏。操作以图标、状态和动效表达，不添加宣传或设计说明文案。

## 普通用户遇到的问题与修复

| 问题 | 修复 |
| --- | --- |
| 搜索状态存在，但展开与筛选过渡被样式覆盖 | 补回输入区伸展、聚焦光影、面板浮入、选项切换；支持 Escape、键盘进入筛选和清除条件 |
| 导航筛选参数与搜索页不一致；分辨率未被服务端处理 | 对齐 sort、resolution、category、tag；实现尺寸、竖屏与超宽屏查询 |
| 分类默认热门列表第二次访问返回 500 | 缓存从 HTTP ResponseEntity 移到可反序列化的业务数据层，增加缓存往返回归 |
| 分类列表显示虚拟导航分组，投稿也误用分组 ID | 提取实际题材分类；检索和投稿提交分类名称；组合筛选保留分辨率 |
| 卡片只有计数，缺少直接点赞收藏；详情点赞用浏览图标 | 统一 ReactionButton 心形／星形；加入弹性缩放、粒子、计数过渡与请求反馈 |
| 失败请求也可能被误认为成功，重复点击提交 | 等待确认后播放成功粒子；请求失败回滚；处理中锁定按钮 |
| 社区图片未收录为壁纸就禁止点赞，收藏入口缺失 | 对齐现有图片互动接口，补全点赞收藏入口 |
| 访问发布页登录后停在原页 | 登录后恢复目标页；取消登录时清除过期跳转目标 |
| 登录不支持 Enter，评论缺少重复提交保护 | Enter 提交、登录行内错误、评论提交状态与访客登录入口 |
| 发布页返回触发两次确认 | 统一由路由离开守卫确认一次 |
| 图片、作者入口仅支持鼠标；手机操作挤压 | 补键盘入口与名称、44px 图标触点、移动卡片操作区、通知栏横向布局 |

## 验证与复跑

- 前端：`npm test`，124 项通过；生产构建通过。
- 后端：75 项测试通过，包含新增的尺寸组合 SQL 回归。
- Windows Java 17 本机测试需 `-DargLine=-Djdk.attach.allowAttachSelf=true`，解决 Mockito 本机附加代理失败；不改变生产 JVM 配置。
- 项目根目录 `after/ux-audit.cjs`：隔离 API 响应的浏览器验收，覆盖搜索、互动成功／失败、评论、登录、发布离开确认、全屏焦点以及 320/390/768/1440 下十个页面。
- 项目根目录 `after/ux-live.cjs`：直接访问正在运行的前后端，不拦截 API，检查公开页面和 HTTP 错误。
- 执行脚本前设置 `$env:NODE_PATH = npm.cmd root -g`，使用本机 Playwright 与 Edge；结果保存在根目录 `ux-browser-results.json`、`ux-live-results.json`。

当前真实图库为空。互动验收采用隔离测试数据，不创建真实用户、不上传作品、不写入正式库。真实接口已检查尺寸、分类组合请求与非法尺寸返回 400；尚无真实作品可验证完整发布到下载的生产数据链路。颜色入口按作品颜色标签筛选，不声称完成像素颜色识别。

## 维护约束

`interactions.css` 为交互层，`immersive-carousel.css` 为轮播层；不要用全局 `animation: none`、隐藏按钮、删除过渡来完成视觉精简。减少动态效果仅在用户系统偏好开启时生效。新按钮保持 aria-label/title、键盘操作、失败回滚与真实接口契约。后续涉及搜索与互动的调整，应复跑上述浏览器脚本。
